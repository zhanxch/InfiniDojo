# InfiniDojo 投稿版本约定

约定日期：2026-10-12；2026-10-13 按用户最新要求重新校准。此文件固定研究范围与证据要求，不代表实验已经完成。
详细实施顺序见 [下一阶段任务](next-stage.md)。

## 主要主张

InfiniDojo 按自然语言需求控制外观、关系和组合复杂度，将操作可行性纳入生成过程，
产出可直接用于 RoboDojo 评测的实例。物理执行用于检验构造是否兑现可行性，不作为新的验证方法贡献。
按需求扩展评测条件是论文主体；同预算产出更多、模型分数下降或排名反转都不是
论文成立的必要条件。“首次/没有同类系统”需文献和已有能力核查，不能预先作为事实。

主结论回答“能否按需求生成可用于评测的实例”；共同验证是实例接受条件，
相同预算是涉及效率比较时的公平性要求，两者不替代主要研究问题。

## 有限范围

- 一个机器人配置：RoboDojo `arx_x5`（保留原生双臂）。
- 三个原生任务：`general_pickup`、`stack_blocks`、`cover_blocks`，分别覆盖拾取、
  重复取放与支撑转换、覆盖物及接触/间隙约束。完整原生任务均须评分，不能只做子步骤。
- 最小资产范围为 Infinigen `CanFactory`，包含 `general_pickup` 的待操作目标及杂物。
  先限定目标的可抓取尺寸/形状域，按实际新几何建立参考操作；不要求堆叠方块、空心杯全部程序化。
  `FoodBoxFactory` 不再是路线打通或投稿前置条件。
- 外观控制先采用具名颜色和目标/干扰物相似度；关系控制采用区域、成对距离和目标相关位置；
  组合复杂度先采用数量及目标/干扰物组成。不将物体尺寸变化视为纯外观干预，也不将 event 数量等同于组合复杂度。
  此处 Appearance 与 InfiniBench 的 Observational（视角/遮挡）不同，应在论文中明确命名。
- 主要机制对照为生成后规划与生成中保留完整交互；固定参考轨迹补全是已有实现的准确定位。
  G3 已有修复可运行的开发证据，冻结为可选机制，不再增加启发式追求优势。
- 两个被测策略：固定 OpenWAM checkpoint 与 XPolicyLab GPT-6 Astra 适配器。
  两者各自比较原生与生成实例，作为同一 RoboDojo 平台上的两类实例来源。

任务选择基于交互差异与现有接口，而非策略分数。若某任务/资产缺乏所需语义或物理接口，
可在开发阶段修改约定并记录理由；正式冻结后不可根据测试结果换任务或资产。
此范围不包含新运动规划器、策略训练、真实机器人迁移、RSI 或因果失败机理分析。

## 方法约定

先在最小任务场景取得合理参考动作，再按 event 的支撑/接触关系补全场景。
cluster 表示共同受约束的对象，机械臂各关节仍可动；稳定抓取期间才使用物体—夹爪附着关系。
释放后物体保留在新支撑关系中，继续影响后续阶段。所有阶段共享同一初始场景。
目标几何或任务关系发生变化时，先实例化相应交互、取得新的参考解，再补全环境；不能盲用旧轨迹。
每次加入场景对象都约束其不破坏参考操作，最终物理回放只作为实现有效性的证据。
当前离散包围体和接触模型不能描述为连续运动或完整接触动力学的形式保证。
如果 cluster 只承载固定参考的运动空间，不独立主张新的 cluster 优化算法。
LLM 是约束前端，迭代收益需要独立证据，不必硬凑独立算法创新。

## 实验约定

1. 生成能力：预先声明条件网格，批量报告符合度、有效率、覆盖与多样性。
2. 方法证据：生成后规划与交互条件生成的对照，报告未经事后修复的构造有效率、限制及端到端成本。
   G3 的现有开发结果足以说明修复流程可运行；不把额外 G3 消融或覆盖任务的 G3 接口列为必要交付。
3. 有效性：原生任务成功和额外物理证据分开；参考失败为未验证，不自动判无解。
4. 策略评测：两个策略各跑原生集与生成集，同一策略的模型、观测、控制适配及预算跨集合固定。
   原生成绩与生成集条件曲线并列，任务权重一致；分布差异不自动解释为单因素因果效应。
   四组为 OpenWAM × 原生/生成、GPT-6 Astra × 原生/生成；此处的两个方法是被测策略，
   与第 2 项的生成方法对照分开。InfiniDojo 生成集仍在 RoboDojo 中执行和评分。
5. 可复现：代码、任务/资产来源、配置、每次请求结果和故障记录齐全，不能只展示成功视频。

开发种子使用 1200–1219，首轮保留种子使用 2200–2223；后续任务的正式清单和总预算在
开发诊断后统一冻结。场景族是统计单位，同族变体和轨迹帧不是独立样本。
参考控制器的物理步数与被测策略的原生动作预算不同，分别报告，不冒充官方榜单复现。

## 停止条件

路线打通的近期目标是三个已有任务的统一描述入口、三个复杂度维度的有界生成控制、
至少一种程序化待操作目标，以及新生成 episode 的 RoboDojo 加载/评测接口证据。
论文实验与该近期工程目标区分：采用共同基准、三个单轴变化及一个联合条件，冻结样本和预算后执行。
上述有限范围内的生成与物理证据、机制对照、两个策略的两组实例比较和复现材料齐备后写稿。
不继续扩资产、机器人、任务或模型以寻找更好数字。开发诊断后只进行一轮有明确问题依据的
核心设计调整，再冻结正式实验；实现错误可以修复，但记录变更并重跑受影响条件。
正式实验不能支持算法优势时，收缩算法主张；不能支持可控生成能力时，明确主要主张未完成。
证据不充分不能以增加模块代替，后续研究另行列出。
